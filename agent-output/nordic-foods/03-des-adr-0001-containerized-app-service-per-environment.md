## 🔍 Context

Requirement 1 and 2 call for a web portal for 500 concurrent users and a private REST API, delivered by 3 developers and 1 DevOps engineer on a budget of about EUR 500/month. The approved assessment decides:

> Compute | Containerized App Service, one plan per environment | Portal and API share a plan to save cost.

> Dev tiers | P0v3 and DTU S0, not B1 and Basic | Repo feature floors control validation; costs +$61.65/month over B1 and Basic.

Source: [02-architecture-assessment.md](02-architecture-assessment.md), Architecture Decision Summary and Resource SKU Recommendations.

## ✅ Decision

Run the portal and the private API as two containerized Linux apps on one App Service plan per environment, on Premium v3 P0v3 with one instance in Dev and in Prod ($64.97/month each). Images come from the shared Container Registry (see [ADR-0005](03-des-adr-0005-private-cicd-runner-and-registry.md)).

## 🔄 Alternatives Considered

| Option                | Pros                                      | Cons                                                              | WAF Impact                          |
| --------------------- | ----------------------------------------- | ----------------------------------------------------------------- | ----------------------------------- |
| Basic B1 (Dev)        | $13.14/month; saves $61.65/month with DTU Basic | Fails the repo VNet-integration floor, so validation would reject it | Cost: +, Operations: -              |
| Standard S1           | Meets the floor                           | $69.35/month, more than P0v3, no zone redundancy                  | Cost: -                             |
| P0v3 x2 (Prod)        | $129.94/month; extra capacity             | Capacity and instance redundancy only; P0v3 is not in the repo zone-redundancy matrix, so zone placement is not established | Performance: +, Cost: -             |

## ⚖️ Consequences

### Positive

- Lowest Premium tier that meets the repo floors; supports a later 1-year reservation ($22.64/month saving on Prod per the worker estimate).
- Separate plans keep Dev load from affecting Prod.

### Negative

- One shared 1 vCPU, 4 GB instance carries both apps in Prod; sizing has no load evidence.
- Dev costs the same as Prod ($64.97 each) because of the repo feature floors.

### Neutral

- Maintainers may reconcile the B1 floor with Learn, which could save $61.65/month.

## 🏛️ WAF Pillar Analysis

| Pillar      | Impact | Notes                                                                            |
| ----------- | ------ | -------------------------------------------------------------------------------- |
| Security    | →      | VNet integration and Managed Identity are available on the chosen tier.          |
| Reliability | ↓      | Single instance; see [ADR-0004](03-des-adr-0004-single-zone-prod-availability-posture.md). |
| Performance | ↓      | 1 vCPU for portal and API at 500 concurrent users is unverified.                 |
| Cost        | ↑      | Cheapest compliant tier; shared plan per environment.                            |
| Operations  | →      | Containers match the Terraform and OIDC deployment path.                         |

## 🔒 Compliance Considerations

- Compute stays in `swedencentral`, supporting the EU residency requirement.

## 📝 Implementation Notes

- Load-test Prod at 500 concurrent users and 150 orders/min before buying any reservation.
- Plan autoscale for the seasonal peak; each extra P0v3 instance costs the same as the first at pay-as-you-go.
- SKUs flow from `sku-manifest.json`; do not re-derive them from this ADR.
